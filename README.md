# NJUGA/CASINO — Android / Capacitor

This project packages the existing NJUGA/CASINO HTML/CSS/JavaScript game as a polished Android application using Capacitor.

## What has been prepared

- Existing game preserved in `www/index.html`.
- Offline-first packaging: remote Google Fonts were removed so the core UI does not depend on an internet connection.
- Mobile safe-area handling and touch-focused UI improvements.
- Capacitor App integration for Android back-button behavior.
- Capacitor Haptics integration for card selection and action feedback.
- Local settings remain available through the game's existing storage system.
- Android launcher/adaptive icon assets.
- Android splash/theme resources.
- Play Store feature graphic and 1024px icon source.
- Privacy-policy starter page and Play Store listing draft.
- API 36 / Android 16 target enforcement script for the generated Android project.

## Quick start

```bash
npm install
npx cap add android
npx cap sync android
```

Then apply native polish:

**Windows PowerShell**
```powershell
.\apply-android-polish.ps1
npx cap open android
```

**macOS/Linux**
```bash
./apply-android-polish.sh
npx cap open android
```

## Build a debug APK

```bash
cd android
./gradlew assembleDebug
```

On Windows:

```powershell
cd android
.\gradlew.bat assembleDebug
```

## Build the Play Store AAB

```powershell
npm run sync
cd android
.\gradlew.bat bundleRelease
```

Configure a release signing key in Android Studio before uploading the final AAB.

## Important

The `android/` directory is intentionally generated by Capacitor so it matches the installed Capacitor/Android tooling on your machine. Do not manually create a fake native project. Run `npx cap add android`, then apply the included native overrides.

See `BUILD-PLAY-STORE.md` for the release checklist and `PLAY-STORE-LISTING.md` for store copy.

## iPhone (iOS)

An iOS build target is included. See **BUILD-IOS.md** (setup, run, App Store release) and **APP-STORE-LISTING.md**. Quick start on a Mac: `./setup-ios.sh`.
